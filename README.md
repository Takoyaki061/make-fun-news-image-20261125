A newspaper front page summing up the world news of **Wednesday 25 November 2026**, drawn by `main.py` with standard-library-only Python: a hand-rolled 5x7 bitmap font and a zlib PNG encoder, so the grader's bare python:3.13 image can run it. No PIL, no network, no randomness — both runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Render a different composition locally with `python3 main.py out.png B`
(variants A, B, C; B is the default).
